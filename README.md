# Отбор вин

[Открыть приложение](https://mmda-hw3-danchikrybakov.streamlit.app/)

Приложение к ДЗ-3 по ММАД оценивает вероятность того, что вино получит не менее 7 баллов, по 11 лабораторным показателям и цвету вина.

## Локальный запуск

Python 3.12. Версии библиотек указаны в `requirements.txt`. Из папки приложения:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Возможности

- «Одно вино» — ввод признаков, вероятность и решение при выбранном пороге.
- «Модельные метрики» — матрица ошибок, precision, recall, F1, ROC- и PR-кривые с текущей рабочей точкой.
- «Загрузка CSV» — пакетный прогноз и скачивание результатов. Пример входного CSV доступен на вкладке; `is_red`: 0 — белое, 1 — красное. Столбец `target` не требуется.
- «Что выучила модель» — отсортированные коэффициенты после масштабирования.

## Модель и качество

В `model.joblib` сохранён обученный пайплайн `StandardScaler` → `LogisticRegression`. Порог 0.23636 из `config.json` выбран на валидации внутри train: максимальный precision при recall не ниже 0.7.

Полные повторы удалены до разбиения. Train содержит 3724 строки, test — 1596. На test при выбранном пороге: precision **0.4213**, recall **0.7063**, F1 **0.5277**. В приложении модель не обучается.

## Кэширование

`st.cache_resource` сохраняет один объект модели между повторными выполнениями скрипта. `st.cache_data` кэширует тестовую таблицу и массив вероятностей, возвращая копии данных. При смене порога вероятности test не вычисляются повторно: меняются предсказанные классы и зависящие от них метрики. Без декоратора `joblib.load` заново читал бы модель с диска при каждом действии пользователя.

Данные: [Wine Quality, UCI](https://archive.ics.uci.edu/dataset/186/wine+quality), P. Cortez et al., 2009, CC BY 4.0. CSV с бинарным таргетом взят из материалов курса ММАД.
